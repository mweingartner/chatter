# Chatter 3.0.2 public release verification — 2026-09-30

Validated on an Apple Silicon M5 Max, macOS 27, Xcode 27 beta. Deployment target is macOS 26; a separate macOS 26/minimum-memory machine was not available for qualification.

- **488-test suite passed:** 328 core, 38 engine, 49 audio, and 73 tooling tests. The optional private-recording transcription test was skipped because no private fixture was supplied. Audio format tests use generated tones only.
- **Dependency independence:** all 12 Swift packages resolved to local filesystem paths with outbound networking denied, from a new scratch directory. Native MLX C/C++ source is populated, and there are no Git submodules or LFS pointers. A clean production build completed using the vendored graph. Upstream native compiler warnings and SwiftPM's unused direct-override warnings remain; the build is not claimed warning-free.
- **Archive and runtime:** extracted the app ZIP to a different directory, verified its ad-hoc signature, and launched it with isolated data, a separate loopback port, login registration disabled, and a system-only PATH. With no models present, it reported the expected setup-required state and created exactly Aiden and Ryan with no recordings.
- **Real synthesis:** restarted that extracted app against existing pinned model files and passed the eight-tool MCP/schema/capability checks for Aiden and Ryan. Each generated a completed Studio WAV with optimistic tone and a separate delivery instruction. The verifier checked native 24 kHz mono PCM24 output. This verifies runtime packaging, not a new 15.6 GB download or subjective voice quality.
- **Local-only listener:** a fresh launch exposed Network.framework EINVAL when a fixed port was supplied in both requiredLocalEndpoint and NWListener's initializer. A four-case native probe isolated the duplicate-port error. Chatter now supplies that port once; the extracted app's local-only HTTP/MCP checks passed.
- **Privacy:** public source starts from a clean snapshot. Prior personal development history, models, recordings, generated narration, API tokens, and diagnostic reports are excluded. An older format-test speech clip was replaced by reproducible mathematical tones in all nine formats. Vendored cryptography test keys and tiny tensor fixtures are public upstream test data, not credentials or speech weights.
- **Binary contents:** all four executables are arm64 and depend dynamically only on system/Swift libraries. Required Metal and SwiftPM resource bundles, MIT/third-party notices, and portable plugin files are included. App/plugin ZIP audits reject runtime data, recordings, model weights, and Python caches.

The first public release is **not notarized**: this machine has no Developer ID distribution identity. Signature integrity, live runtime success, GitHub publication, and Apple notarization are separate claims. No lower-memory performance guarantee, Intel support, cloud-client tunnel, or end-user listening approval is asserted.
